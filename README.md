# Meridian Coast

An original open-world action game under active development. Native C++20,
Direct3D 12, optional DXR 1.1 ray tracing, Win32/XInput, and WASAPI. All geometry,
music, sound, typography, and world content are generated by original code.
No game engine, third-party runtime library, external asset, or package manager.

This is an early implementation, not a claim of GTA 6 quality or completeness.
See [PROGRESS.md](PROGRESS.md) for verified results, limitations, and scorecards.

## Build on Windows

Install the Microsoft Visual Studio C++ x64 build tools and a current Windows
10/11 SDK that includes DXC. These are development tools; players do not need
them. From the repository root:

```bat
build.bat
```

The executable is `build\Release\MeridianCoast.exe`. Distribute that file alone.
Shaders are compiled into it, and the C/C++ runtime is statically linked. Windows
system DLLs are provided by the operating system. `build.bat Debug` builds the
debug configuration. The default build also runs simulation tests and verifies
the executable imports only Windows system libraries.

## Play

Double-click `MeridianCoast.exe`, then press Enter to enter the city. A D3D12 GPU
with Shader Model 6 is required. Ray tracing automatically requires DXR 1.1;
the raster renderer supports devices without it. Native GPU compatibility and
frame rates remain under validation.

| Action | Keyboard / mouse | Controller |
| --- | --- | --- |
| Move / drive | WASD | Left stick |
| Look | Mouse | Right stick |
| Enter / exit vehicle | E | Y |
| Sprint | Shift | A |
| Jump / handbrake | Space | X / B |
| Fire / aim | Left / right mouse | Right / left trigger |
| Reload | R | X |
| Accept nearby contract | M | D-pad up |
| Radio station | Q | D-pad right |
| Pause | Escape | Start |
| Save / load | F5 / F9 | Pause menu save |
| Fullscreen | F11 | Settings |
| Performance display | F3 | — |

Settings, saves, and a session log live under `%LOCALAPPDATA%\MeridianCoast`.
Progress autosaves when exiting normally. No additional input files are needed.

## Validation

```sh
./tools/test-portable.sh
```

Runs portable C++ simulation tests on Linux; it does not test D3D12 or Windows.
The Windows CI builds Release and Debug, audits PE imports, runs simulation
tests, and launches a D3D12 WARP smoke test with a captured BMP. WARP is software
rendering, not hardware DXR or performance validation.

```powershell
./tools/smoke.ps1 -Executable ./build/Release/MeridianCoast.exe
```
